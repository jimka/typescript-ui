# @jimka/create-tsui-app

Scaffold a minimal [`@jimka/typescript-ui`](https://github.com/jimka/typescript-ui) starter project.

## Usage

```bash
npm create @jimka/tsui-app my-app
cd my-app
npm install
npm run dev
```

Omit the directory name to be prompted for one:

```bash
npm create @jimka/tsui-app
```

## What it generates

A minimal Vite + TypeScript project that renders one real `@jimka/typescript-ui`
component, with `dev`, `build`, `typecheck`, and `preview` scripts already wired
up and `@jimka/typescript-ui` installed as a dependency.
